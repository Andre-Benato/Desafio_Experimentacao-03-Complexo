# Desafio 03 — Sistema de processamento de pedidos

**Linguagem:** Java

## Objetivo

Desenvolver uma solução em Java para processar pedidos
de compra de produtos.

A solução deverá considerar os produtos solicitados,
suas quantidades, os valores envolvidos e as informações
necessárias para concluir o processamento do pedido.

O projeto deverá compilar e permitir a execução de
testes automatizados.

## Estrutura esperada

A solução deverá contemplar as seguintes classes:

- `Produto`
- `ItemPedido`
- `Pedido`
- `ProcessadorPedidos`

## Operação principal

A classe `ProcessadorPedidos` deverá disponibilizar
uma operação para processar uma lista de itens de pedido
e um CEP de destino.

## Orientações

- Implemente a solução no projeto existente.
- Respeite os nomes das classes.
- Utilize Java.
- Não implemente interface gráfica ou entrada de dados pelo console.
